# Support

For setup and non-sensitive product issues, use
[GitHub Issues](https://github.com/flin-agency/flin-ga4-mcp/issues).
Include the package version, operating system, Claude version, failing tool name,
sanitized error code and whether `health_check` reports configuration or sign-in problems.

Do not include OAuth secrets, token files, full environment dumps, private
GA4 results or unredacted client logs. A public issue is not a channel
for confidential vulnerability reports.

For private security or privacy concerns, contact **flin@flin.agency**.
Publisher: flin GmbH, Weinbergstrasse 31, 8006 Zürich, Switzerland, as listed in
the [company imprint](https://flin.agency/impressum/).
Describe the issue without including live credentials; agree a suitable channel
before transferring any sensitive diagnostic material.
